# BLUEMSX.pak

A simple NextUI launcher for the blueMSX core that comes with the RetroArch pak. You install the RetroArch pak on the device from the Pak Store.

Supports TrimUI tg5040 devices only.

## Installation

1. Download `BLUEMSX.pakz`.
2. Put it in the root of the SD card.
3. Reboot the device. The pak installs automatically.
4. Install RetroArch from the Pak Store.
